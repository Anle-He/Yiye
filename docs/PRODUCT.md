# 产品边界

## 一句话定位

用最低操作成本记录“我读完或看完了什么、何时完成、感受如何”的本地 Windows 小工具。

## 设计原则

1. **记录先于整理**：标题和类别足以保存，其余字段均可跳过。
2. **事实先于补全**：只保存用户输入，不臆造作者、封面、评分或短评。
3. **作品先于记录**：首页以书籍或影视作品为单位；历次阅读和观看属于作品内部。
4. **本地先于服务**：无需注册、联网或订阅，数据由用户掌控。
5. **渐进披露**：常用操作直接可见，低频能力不占据主界面。

## 第一版包含

- 新增、编辑、删除书籍或影视作品
- 为同一作品保存多张本地封面，以视觉方式区分版本
- 为同一作品追加多次阅读或观看记录
- 查看已有未完成体验和历史进度，并将原体验补记完成
- 按标题、副标题或作者搜索，按类别筛选
- 轻量统计：作品总数、完整评分次数、累计完成次数

## 第一版不包含

- 账号、云同步、多设备协作
- 动态、关注、评论、排行榜或推荐
- 自动抓取封面、ISBN、演员、导演等外部资料
- 复杂标签树、书架管理、借阅管理
- 单集标题、季/集资料库、后台计时器、目标打卡和提醒
- 手动导出、导入与回滚本地备份

## 作品

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 用户输入的作品名 |
| 副标题 | 否 | 详情页展示的补充标题，不占用左侧列表空间 |
| 作者 | 否 | 仅书籍使用；详情页展示并参与搜索 |
| 封面 | 否 | 最多 20 张本地图片；第一张作为主封面 |
| 类别 | 是 | 书籍 / 影视 |
| 当前状态 | 自动 | 按已有体验派生，用于数据一致性 |

## 每次阅读或观看

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 开始日期 | 否 | 保留已有记录的开始日期 |
| 结束日期 | 完成时是 | 完成本次时默认当天；不得早于开始日期 |
| Allure | 否 | 1–3 分，综合分中权重为 1.5 |
| Immersion | 否 | 1–5 分 |
| Rationality | 否 | 1–5 分 |
| Illumination | 否 | 1–5 分 |
| 总结 | 否 | 完成本次时填写的一段自由文本 |

## 历史记录

已有未完成体验可在作品详情查看、补记完成或删除。历史进度保留日期、时长或集数及随手记，在记录窗口中只读展示。补记完成更新原体验，保留原始笔记、开始日期和进度关联。

只有一次体验完成后才允许留下最终评分。单次四项全部填写后，应用只读显示 `Rank = (Allure × 1.5 + Immersion + Rationality + Illumination) ÷ 5`。作品综合分是所有“已完成且评分完整”的单次 Rank 平均值，只在最终结果保留一位小数，并以 `x.x / 3.9 · N次评分` 呈现。中途记录、未完成体验和评分不完整的体验都不参与计算。

## 第一版完成标准

- 从打开新增窗口到加入一部只有标题的作品，不超过三个明确动作。
- 同一作品在作品库中只出现一次，详情可追加任意多次阅读或观看。
- 补记已有体验的完成日期时保留其 ID 和历史进度。
- 断网时全部核心能力可用。
- 退出并重新打开后记录不丢失。
- 没有填写的信息保持为空，不用占位内容伪装完整。
