# 界面设计

一页用于保存书籍、影视及每次阅读或观看的记录。首页以浅灰画布上的封面书架和分类统计组织内容，作品库与详情通过独立面板区分资料和记录。窄导航保留主要页面入口，搜索和添加作品始终位于窗口顶栏。

## 页面参考与对应实现

首页参照 Koodo Reader 的封面书架与 Anx Reader 的统计层级；详情参照 Anx Reader 的笔记分区。参考重点是封面、数字、标题与记录各自承担的信息层级。

## 色彩、字体与图片

浅灰画布与白色面板构成两层背景，面板的圆角、内边距和区域间距帮助辨认内容归属。真实封面提供主要色彩；正文、次要信息和分隔线通过明度区分。强调色用于选中状态、主要操作和焦点。

| 用途 | 色值 | 使用位置 |
| --- | --- | --- |
| 页面画布 | `#F0F1F5` | 首页、作品库和详情的面板外背景 |
| 导航底色 | `#E1E7E9` | 固定窄导航区 |
| 内容面板 | `#FFFFFF` | 作品分区、资料、记录和表单 |
| 次级表面 | `#F1F4F3` | 最近完成条目和记录区域 |
| 正文 | `#2E3738` | 作品名、字段内容、笔记 |
| 辅助文字 | `#626E72` | 日期、数量和说明 |
| 主要操作 | `#356D67` | 添加、保存和焦点强调 |
| 选中背景 | `#D5E8E3` | 当前导航和类别选择 |
| 分隔线 | `#E2E7E6` | 面板内的内容分区 |
| 评分提示 | `#8B643D` | 作品评分标记 |

这些资源集中在 `Themes/ApplicationTheme.xaml`。中文使用系统界面字体，作品标题为 15、感想正文为 16，作者、日期、数量和评分说明至少为 13（WPF 逻辑像素）；分区标题为 18–20，详情主标题为 22–24。辅助文字使用 `#626E72`，通过字重与颜色建立层级。小窗口沿用相同正文与辅助字号，通过封面尺寸、间距和分页适配可用空间。

首页与作品库使用竖向封面，图片等比缩放，保留完整内容，标题放在封面下方。长标题按可用空间截断，悬停可查看完整名称。无封面时使用类别占位，作品标题仍随条目显示。图片尺寸和条目间距随窗口调整。

## 页面组织

### 顶栏与导航

全局搜索覆盖全部类别中的作品名、副标题和作者，按 Enter 或点击搜索图标后进入作品库展示结果。添加作品入口在各页保持同一位置。窄导航通过图标、短标签和选中背景标记当前首页或作品库；从列表进入详情后，返回入口说明将回到首页、作品库或所选月份。

### 首页

页头分别展示读过的书籍数与看过的影视数。统计按已有完成记录的作品去重，重读或重看仍计为同一作品；收藏但尚未完成的作品不计入该总量。图标区分类别，数字强调数量，比例条展示书籍与影视在已完成作品中的占比。

最近完成展示最多六部作品，封面排成一行，下方居中显示最多两行作品名，优先在完整词语之间换行，再尽量均衡两行宽度，超出部分省略，悬停可查看完整名称，每部均可直接打开。下方由书籍榜单、影视榜单和作者词云组成。书影各显示前三项，首位使用较大的封面与分值，后两位以紧凑封面行排列；序号标明次序，短条形刻度表示当前分数占满分 3.9 的比例。浅绿、暖白与灰绿表面区分三组内容，作品条目可直接进入详情。

作者词云选取评分最高的八位作者，以横竖混排组成紧凑的中心布局。最高分作者与长姓名保持横向，部分二至四字的中文姓名采用正向字形竖排。入选作者的评分从低到高映射为 18–30 号字，同分使用同字号；全部同分时使用 24 号字。小窗口将所有词项字号统一乘以 0.9，最小字号为 16.2。空间不足时保留排名靠前的作者，标题旁显示实际人数。悬停或键盘聚焦姓名可查看完整姓名、5.0 分制评分和已评本数，按 Esc 收起提示。长姓名按可用宽度省略，词项之间保留间隔，窗口缩放后保持稳定的排布规则。

每次阅读或观看的日期、评分与感想集中在作品详情中查看。常用窗口下，各区在一屏内呈现；较小窗口调整封面尺寸和间距，保留可读字号。

空库时提供添加第一部作品的入口；已有作品但尚无完成记录时，说明可以打开作品补记完成日期。

### 作品库

作品库默认展示全部作品，书籍与影视分别位于白色面板中。每个分区包含类别标题、数量和封面网格，标题紧随封面。页头提供全部、书籍、影视筛选，以及封面和月份两种视图切换。全局搜索结果与类别筛选共同决定当前显示内容，空分组不占位置。

每页数量根据内容区的宽高调整，多于一页时使用翻页操作。封面区域与翻页入口保持在当前窗口内，窗口缩小时减少每页数量，保持作品名和按钮可读。

月份视图按最近记录日期分组，每个月份由少量错位封面组成卡叠，卡片头部显示月份和作品数。打开月份后展示该月作品；返回月份概览时恢复对应卡叠。月份卡叠、作品封面与详情页照片堆保留封面过渡。

从详情返回作品库时，恢复筛选条件、月份、所在页和作品焦点，方便继续浏览。

### 作品详情

左侧白色面板集中呈现作品封面、标题、副标题、作者与操作。多张本地图片使用照片堆呈现，点击封面进入管理窗口；记一次阅读或观看、编辑资料与删除作品的操作位于资料之后。每次完成的日期保留在右侧对应记录中。

右侧白色面板用于完成记录与笔记，与左侧资料通过灰色间隔分开。完成记录按日期排列，每条记录包含日期、编辑入口、笔记和四维评分。四项评分以两行两列组成独立区域，名称使用 Allure、Immersion、Rationality 和 Illumination，采用 Monotype Corsiva 书写体及 Gabriola、Palatino Linotype 后备字体。名称前段以 32 号绿色强调，余词为 25 号；暖金棕色的 44 号分值与 18 号分母建立主次。记录边框以铜、银、金色对应已有评级，未完整评分使用中性色和提示。较窄的记录区域将日期与编辑入口合为横向记录头，为笔记和评分保留空间。常规作品摘要与简短记录一屏呈现；多次记录或长笔记通过整页滚动访问，记录列表随内容展开。

左侧资料中的综合评分使用独立的浅暖色区域，以大分值和较小上限建立主次，评分次数和完成次数位于同一区域。综合分汇总作品的已评分记录，右侧四维分值属于各次记录，二者通过位置与标签区分。

作品综合分满分为 3.9，作者分换算为 5.0；具体计算规则见 [产品边界](PRODUCT.md)。已有未完成记录继续提供查看和补记入口，历史进度保留在记录窗口中。

### 表单与封面管理

新增和编辑使用模态窗口。字段名称、必填标记、帮助文字与错误信息各有固定位置；较长内容可以滚动。评分下拉框支持键盘选择，保存时保留各维度的实际选择值。封面管理展示本地图片、主封面状态，以及添加、调整和删除操作。

## 界面文字

按钮直接说明动作与对象，例如“添加作品”“管理封面”“编辑记录”“保存”。帮助文字补充搜索范围、图片格式或评分上限。空状态说明当前内容，并给出适用的操作入口。

书籍与影视共享页面结构，单次记录使用相应的阅读或观看称呼。日期、数量、评分和状态来自已有数据；可选字段为空时隐藏对应内容。

## 验证重点

布局验证覆盖首页封面、作品库两种视图、详情和表单。检查窄窗口、长标题、空封面、无笔记和评分不完整时的显示；首页与作品库优先验证一屏可见，长记录验证整页滚动可达，封面、标题与操作保持在水平可用范围内。

交互验证包括封面打开正确作品、全局搜索切换页面并返回正确结果、类别与月份筛选、翻页、返回后的页码和焦点、评分选择与保存。测试根据内容边界和实际操作检查布局，列数与每页数量由可用空间决定。

`UiSmokeTests` 可通过 `QUIETSHELF_UI_SNAPSHOT_DIR` 输出截图，用于检查字号、留白、图片和截断。真实资料的视觉预览使用临时数据库副本，原始数据库与封面保持不变；实际安装版本还需单独启动验证。
